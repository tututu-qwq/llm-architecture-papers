# 大模型架构入门论文 / LLM Architecture Reading List

从最简单的 Transformer 到现代开源骨架与架构变体的入门阅读清单。  
A beginner-friendly reading list from Transformer foundations to modern open-source LLM architectures.

**建议阅读顺序 / Suggested order:** `01 → 13`

PDFs are downloaded from [arXiv](https://arxiv.org/) (and OpenAI CDN for GPT-1 / GPT-2) for personal study. Copyright remains with the original authors and publishers.

## Reading path (brief)

1. **01–03** — Transformer / decoder-only (GPT) / encoder-only (BERT)
2. **04–06** — Scaling and text-to-text (GPT-2, GPT-3, T5)
3. **07–10** — Modern open-source stacks (LLaMA, Llama 2, Qwen2, Gemma 2)
4. **11–13** — Architecture variants (MoE, Mixtral, Mamba)
